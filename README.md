# API-тесты сервиса «Яндекс Самокат»

Проект автоматизированного тестирования REST API сервиса «Яндекс Самокат».

## Покрытие

Проверены основные сценарии работы API:
- создание курьера;
- авторизация курьера;
- создание заказа с BLACK, GREY, двумя цветами и без указания цвета;
- получение списка заказов;
- удаление курьера;
- принятие заказа курьером;
- получение заказа по трек-номеру.

Для позитивных и негативных сценариев проверяются HTTP-коды и тела ответов. Для вариантов входных данных используется параметризация. Тестовые сущности создаются независимо для сценариев и очищаются после выполнения, где это поддерживается API.

## Стек

Python, Pytest, Requests, Allure.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest tests -v --alluredir=allure_results
```

## Allure

```bash
allure serve allure_results
```
